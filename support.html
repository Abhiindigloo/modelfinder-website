Let’s make it useful.

Get help or report an issue

Use our GitHub issue tracker for website bugs, accessibility problems, or questions about Model Finder. A GitHub account is required to post.

Include what you expected, what happened, and the relevant browser or plugin version. Do not post API keys, private prompts, personal information, or confidential documents. Issues are public.

Using Model Finder

Select the installed Model Finder plugin in ChatGPT and describe your task and quality requirements. The website’s prompt builder can help you write that brief.

The website does not install the plugin, query providers, or execute evaluations. Model Finder provides research and planning guidance using the tools available in its host.
