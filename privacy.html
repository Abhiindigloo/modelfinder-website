MODEL FINDER / PRIVACY

Simple by design.

Effective October 12, 2026. This notice describes the Model Finder website and the skills-only Model Finder plugin.

This website

The website has no accounts, advertising, analytics scripts, cookies, or application database. Usage imports, prompt-builder and calculator inputs are processed in your browser and are not sent by this website to a model provider or stored by the website. Imported analytics records are held only in this tab’s application memory and are cleared on reload, tab closure, or Clear. No prompts or responses are required in the import. The selected file is read locally and is not uploaded. Clicking Copy writes the generated prompt to your clipboard at your request.

Hosting and external services

GitHub Pages hosts this website. GitHub may process technical request information, including IP addresses, under its privacy statement. External links take you to services with their own policies. GitHub issues and their contents are public.

The plugin in ChatGPT

Model Finder is a set of instructions for the host assistant; it does not include its own inference endpoint, analytics service, or data store. Messages you send in ChatGPT and any tools used there are handled under the host’s and applicable connected services’ policies. This website does not receive those conversations. Avoid sharing secrets or confidential information in public issues or comparison examples.

Publisher and payments

Indigloo is the publisher selected by the creator. No payment processor, billing account, or checkout is connected to this website. Paid analytics is planned but unavailable; privacy disclosures must be updated before payment or account data collection is enabled.

Questions

Use the support page for privacy questions. Please do not disclose private information in the public issue tracker.
